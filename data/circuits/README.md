# Circuit geometry provenance

The following circuit centerline and width data are adapted from **TUMFTM/racetrack-database**:
https://github.com/TUMFTM/racetrack-database

Upstream data contains smoothed centerline coordinates in metres and left/right track widths. The upstream README states that centerlines were derived from OpenStreetMap GPS points and widths were estimated from satellite imagery. The data is not an official FIA or Formula One publication; accuracy can vary by circuit and should be validated against current official circuit maps before treating any layout as a certified simulation reference.

Included layouts:
- Circuit of the Americas (Austin)
- Red Bull Ring (Spielberg)
- Silverstone
- Autodromo Nazionale Monza
- Circuit de Spa-Francorchamps
- Suzuka
- Albert Park (Melbourne)
- Bahrain International Circuit (Sakhir)
- Hungaroring (Budapest)
- Circuit Gilles-Villeneuve (Montreal)
- Shanghai International Circuit

OpenStreetMap data is © OpenStreetMap contributors and is available under the Open Database License (ODbL): https://www.openstreetmap.org/copyright

These are geometric track surfaces derived from public map data, not copied game assets. Circuit-specific elevation, kerb profiles, pit lanes, run-off surfaces, buildings, marshal posts and event-year configuration are not yet modelled with the same source coverage.
